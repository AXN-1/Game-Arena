🎮 Game Hub Website
A modern, interactive gaming hub website built with HTML, CSS, and JavaScript.
It features a Hotstar-style layout with a hero section, sidebar navigation, and multiple mini-games like Snake, Tic Tac Toe, Memory Match, Breakout, Flappy Bird, Space Invader, and Bubble Shooter.

✨ Features
Hero Section: Large poster-style banner with title, description, and Play button.

Sidebar Navigation: Expanding sidebar with glowing hover effects.

Game Cards: Attractive cards with background images, hover animations, and Play buttons.

Fade-in Animation: Smooth entry effect for game list items.

Responsive Layout: Works across different screen sizes.

Footer Section: Clean, minimal footer design.

🛠️ Tech Stack
HTML5 – Structure

CSS3 – Styling, animations, responsive design

JavaScript (ES6) – DOM manipulation, fade-in effects

📂 Project Structure
Code
├── index.html        # Main HTML file
├── style.css         # Styling for layout, cards, sidebar, hero section
├── script.js         # Fade-in animation for game list
├── images/           # Game thumbnails (snake.jpg, breakout.jpg, etc.)
